# Data Information Visualization

This repository contains practical assignments completed as part of the **Information Visualization** course.

The projects explore different visualization techniques using JavaScript libraries and interactive visual tools.

## Practical Assignments

### Graphical Representation with D3.js
Exploration of data visualization using D3.js, including graphical representations and interactive visualizations.

### Geographic Visualization
Visualization of geographical data using the ArcGIS JavaScript API and D3.js. The assignment focuses on earthquake data, magnitude classification, map customization, and interactive popups.

### Network Visualization
Representation and exploration of network data through graphs, nodes, and links, including force-directed layouts and interactive features.

## Technologies Used

- **HTML5** – Structure of the visualizations.
- **CSS3** – Styling and visual design.
- **JavaScript** – Visualization logic and interactivity.
- **D3.js** – Data-driven visualizations and graphical representations.
- **ArcGIS JavaScript API** – Geographic data visualization and interactive maps.

## Running the Projects

1. Clone the repository:

   ```bash
   git clone https://github.com/Nour226/Data-Information-Visualization.git
   ```

2. Open the repository folder in Visual Studio Code.

3. Open the desired TP or exercise.

4. Run the corresponding HTML file using **Live Server**.

Some exercises require an internet connection to load external libraries or map services.
